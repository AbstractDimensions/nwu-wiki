## How this list is maintained

Names come from a student’s verified spreadsheet of active South African
bursaries and scholarships. It is alphabetical and deliberately unopinionated —
the value is in the Notes column, which is empty because nobody has filled it
in yet. That part is the wiki’s job, and yours.

*Spotted a dead programme? Strike it through. Found a new one? Add it. That is
how this page stays useful.*
