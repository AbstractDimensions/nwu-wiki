# Dr. Example Lecturer (template)

> [!note]
> This is an uneditable example page showing the template structure for Lecturer pages.

## Classes

- CMPG 111 — Introductory Programming (Semester 1)
- CMPG 121 — Structured Programming (Semester 2)
- CMPG 211 — Object-Oriented Programming (Year 2)

## Consultation

- Tuesdays and Thursdays, 10:00–12:00, during term time
- Booking: knock with your student card visible — no appointment system

### What to bring

Bring the specific error message or the exact question number. "I don't understand chapter 3" gets you sent back to chapter 3.

## Assessment style

| Item | Format | Notes |
|---|---|---|
| Semester tests | Written, 2 hours | Code on paper — practice handwriting code |
| Practicals | Weekly lab submissions | Best 8 of 10 count |
| Exam | Written, 3 hours | 50% subminimum per module rules |

## Teaching style

- Live-coded classes: examples are written in front of the class
- Past class examples resemble test questions, so redoing them is good preparation
- Email replies usually within a day; weekly announcements on eFundi on Monday mornings
